# Healthcare Analytics for Doctor Visits

## 📌 Project Overview

This project focuses on **Healthcare Analytics for Doctor Visits**.
The main purpose of this project is to analyze healthcare-related data and find useful patterns that may affect the number of doctor visits.

The dataset contains information about people's **age, gender, income, illnesses, health condition, chronic conditions, healthcare support, and doctor visits**.

The project uses data analysis and visualization techniques to understand the relationship between these factors and doctor visits.

---

## 🎯 Project Objective

The main objectives of this project are:

* To understand the healthcare dataset.
* To analyze the number of doctor visits.
* To study the effect of age and gender on doctor visits.
* To analyze the relationship between illness and doctor visits.
* To study the effect of general health conditions.
* To understand the role of chronic health conditions.
* To compare healthcare support with doctor visits.
* To create simple visualizations for better understanding.
* To find useful patterns from the dataset.

---

## 📊 Dataset Information

The dataset contains:

* **Records:** 5,190
* **Columns:** 13
* **Main focus:** Doctor visits and related healthcare factors.

### Important Columns

| Column       | Description                            |
| ------------ | -------------------------------------- |
| `visits`     | Number of doctor visits                |
| `gender`     | Gender of the person                   |
| `age`        | Age of the person                      |
| `income`     | Income level                           |
| `illness`    | Number of illnesses or health problems |
| `reduced`    | Days affected by health problems       |
| `health`     | General health condition               |
| `private`    | Private healthcare/insurance support   |
| `freepoor`   | Free healthcare support                |
| `freerepat`  | Special healthcare support             |
| `nchronic`   | Chronic health condition               |
| `lchronic`   | Long-term chronic health condition     |
| `Unnamed: 0` | Record/row identifier                  |

These columns are grouped into personal, financial, health, healthcare-support, and doctor-visit information.
